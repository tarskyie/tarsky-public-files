GitHub Последняя версия программы
Средство разработки и развёртывания информационных сайтов «Крепыш», дополненное с помощью генеративного искусственного интеллекта

Проект посвящён разработке приложения для разработки и размещения в общем доступе интернета информационных сайтов. Целью является создание инструмента, использующего генеративный искусственный интеллект и упрощающее создание веб-сайтов. В рамках проекта ведётся работа по разработке двух программы для Windows, его компонентов и справочников для пользователей. Реализация будет осуществляться с использованием фреймворка .NET. Ожидается, что продукт проекта упростит повышение осведомлённости.
