GitHub  Последняя версия программы
Средство разработки и развёртывания информационных сайтов «Крепыш», дополненное с помощью генеративного искусственного интеллекта

Проект посвящён разработке приложения для разработки и размещения в общем доступе интернета информационных сайтов. Целью является создание инструмента, использующего генеративный искусственный интеллект и упрощающее создание веб-сайтов. Ожидается, что продукт проекта упростит повышение осведомлённости.

После установки программы из инсталлятора Krepysh-Installer вам следует настроить подключение к OpenAI API-совместимому провайдеру. Такой сервер можно запустить с помощью программы TarskyTGI. Если у вас авторизован GitHub Cli, можно загрузить сайт в GitHub Pages из менеджера проектов Krepysh.

В редакторе сайтов (SDATweb.exe) можно создавать/удалять страницы, использовать генеративный искусственный интеллект для их изменения, настраивать навигацию и свойства сайта. С помощью локального сервера Krepysh сайт можно просмотреть в своём браузере.
