TarskyTGI это Windows приложение для использования локальных языковых моделей, работающих на библиотеке GGML. Поддерживаются модели с вводом изображений (llava-1.5 и др.). Для сборки нужен Visual Studio 2026 и инструменты Windows App. Программа испоьзует Python с библиотеками llama-cpp-python, uvicorn и fastapi.
